# Unlox Academy - Week 04 Minor Project (React)

## Project Overview
This project is a React-based application containing two mini-projects: a **To-Do App** and a **Notes App**, built as part of the Unlox Academy Web Development Week 04 curriculum.

## Features Implemented
### 1. To-Do App
* Add new tasks
* Mark tasks as completed or pending
* Edit existing tasks
* Filter tasks (All, Completed, Pending)
* Local Storage integration for data persistence

### 2. Notes App
* Create new notes with titles and content
* Edit existing notes
* Delete notes
* View note creation timestamps
* Local Storage integration

## Technologies Used
* React.js (Functional Components, Hooks like `useState` & `useEffect`)
* JavaScript (ES6+)
* HTML5 & CSS3
* Vite
